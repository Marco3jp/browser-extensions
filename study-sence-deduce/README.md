# study-sence-deduce

dev / stg / prod のように複数の環境を行き来しながら開発するときの小道具をまとめた Chrome 拡張。

- 環境リボン: 開いているページがどの環境かを、左下の斜めのリボンで表示する
- 環境スイッチャー: ポップアップから、同じパスのページを別の環境で開き直す
- テンプレURL: パス・クエリ・ハッシュを保存しておき、ラベル・メモ・タグで探して今の環境で開く

## 入れ方

```bash
npm ci
npm run build
```

`chrome://extensions` のデベロッパーモードで「パッケージ化されていない拡張機能を読み込む」に `dist/` を指定する。

## 使い方

拡張機能のオプションで環境セットを登録する。1つのセットに環境ごとの `hostPattern`（判定用。`*.dev.example.com` 形式）と `hostTemplate`（切り替え先のホスト）を並べる。

設計は `PLAN.md`、決めたことと残っている課題は `HANDOFF.md` にある。
