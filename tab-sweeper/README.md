# Tab Sweeper

溜まったタブをまとめて閉じるための Chrome 拡張。
ポップアップに「重複」と「検索」の2つのタブがある。全ウィンドウのタブが対象
（シークレットウィンドウは、拡張がシークレットで許可されていない限り見えない）。

ツールバーのアイコンには、重複で閉じられるタブの枚数がバッジで出る。

## 重複

URL が完全に一致するタブを URL ごとに並べ、1枚だけ残して閉じる。

- 「すべて閉じる」: 全 URL について1枚だけ残して閉じる
- 「N 枚閉じる」: その URL だけ閉じる
- ラジオボタン: 残すタブを選び直す（打ち消し線のタブが閉じられる側）

`tab.url` の文字列が完全に一致するものだけを重複とみなす。
`#hash` やクエリの違い、末尾の `/` の有無も別の URL として扱う。

何も選ばなければ、残すタブは次の順で決める。

1. いまのウィンドウで表示中のタブ
2. 他のウィンドウで表示中のタブ
3. ピン留めされたタブ
4. 最後に触ったタブ（`lastAccessed`）

## 検索

入力した文字列を URL・タイトルに含むタブを並べ、チェックしたものを閉じる。

- 対象は「URL・タイトル」「URL」「タイトル」から選ぶ
- 大文字小文字は区別しない
- 「正規表現」を ON にすると `RegExp` として扱う（例: `localhost:\d+`、`^https://github\.com/.+/pull/`）
- 「ピン留めを除く」は既定で ON。うっかりピン留めを閉じないため
- 一致したタブは最初から全部チェックされている。残したいものだけ外す

## 入れ方

ビルドは不要。

1. `chrome://extensions` を開く
2. 右上のデベロッパーモードを ON
3. 「パッケージ化されていない拡張機能を読み込む」でこのディレクトリを指定
